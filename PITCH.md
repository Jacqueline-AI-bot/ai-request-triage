# Kurzbeschreibung für Bewerbung / GitHub

Dieses Mini-MVP zeigt eine AI-gestützte Triage-Logik für eingehende Geschäftsanforderungen.

Der Fokus liegt nicht auf einem großen Produkt, sondern auf dem schnellen Übersetzen eines realen Prozessproblems in einen testbaren Prototyp: Anfrage rein, strukturierte Analyse raus.

Das Tool kategorisiert Inhalte, bewertet Priorität und Automatisierungspotenzial, schlägt nächste Schritte vor und erzeugt einen ersten Antwortentwurf. Damit eignet es sich als Grundlage für interne AI-Workflows, Prompt-Bibliotheken und Enablement-Formate.
